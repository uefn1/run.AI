# ゲーム制作仕様(このファイルを書き換えるとAIの開発内容が変わります)

## 概要
ブラウザで動作する2Dブロック崩しゲーム「Neon Breaker」を開発してください。

## 技術要件
- HTML + CSS + JavaScript(依存ライブラリなし、ビルド不要)
- 構成: game/index.html、game/style.css、game/game.js
- game/index.html をブラウザで開くだけで遊べること

## ゲーム仕様
- キャンバスサイズ: 800x600
- パドル: 左右矢印キー(およびマウス)で操作
- ボール: 壁・パドル・ブロックで反射、落下したらミス
- ブロック: 8列 x 5行、色分け(上段ほど高得点)
- スコア・残機(3)・現在のレベルを画面上部に表示
- ブロックを全消去すると次のレベル(ボール速度アップ)
- 残機がなくなったらゲームオーバー表示とリスタート(スペースキー)
- 一時停止(Pキー)

## 品質要件
- node --check game/game.js で構文エラーがないこと
- リサイズ・高DPI環境でも崩れないレイアウト
- 日本語のUI表示
